# Python Crash Course

This repository contains my solutions, notes, and projects completed while working through the book Python Crash Course (3rd Edition) by Eric Matthes.

The goal of this repository is to reinforce Python fundamentals, practice problem-solving, and document my progress as I complete each chapter.

## Learning Objectives

- Build a solid foundation in Python.
- Practice writing clean and readable code.
- Strengthen problem-solving skills.
- Learn Python through hands-on exercises and projects.
- Track my progress throughout the book.
